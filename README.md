# MonsoonCover

MonsoonCover is a hackathon project exploring evidence-gated, loan-linked parametric climate protection for MSMEs.

The project is currently in the specification and architecture phase. Application development has not started.

## Source of truth

Read [`MONSOONCOVER_SPEC.md`](./MONSOONCOVER_SPEC.md) completely before proposing or implementing changes. It defines the frozen product scope, real-world roles, evidence rules, sandbox boundaries, workflow, architecture, testing requirements, and non-negotiable build rules.

## Important disclaimer

MonsoonCover is a hackathon prototype. It is not a lender, insurer, insurance intermediary, or payment service. Demo borrowers, loans, partner systems, and financial events are synthetic or sandboxed unless explicitly classified and evidenced otherwise. No referenced lender or insurer is a project partner unless documented separately with authorization.

## Collaboration

Contributors work on short-lived branches and submit pull requests into `main`. Direct work on `main` is not the team workflow. See [`CONTRIBUTING.md`](./CONTRIBUTING.md).
